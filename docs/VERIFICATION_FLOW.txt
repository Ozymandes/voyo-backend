================================================================================
                           KEY INSIGHTS
================================================================================

1. MASTER LIST IS NOT SCRAPED
   → It's a trusted GUIDE that tells pipeline WHAT to look for
   → Pipeline then VERIFIES each entry externally

2. MULTIPLE VERIFICATION LAYERS
   → You curated it (human verification)
   → Google Places has it (platform verification)
   → Wikipedia has it (cultural verification)
   → Data matches (consistency verification)

3. IF VERIFICATION FAILS
   → Google Places can't find it? Skipped (not inserted)
   → Data doesn't match? Skipped (not inserted)
   → Only VERIFIED POIs reach database

4. SUCCESS RATE
   → 91% (41 out of 45 POIs inserted)
   → 4 failed (could not find on Google Places)

5. is_verified = TRUE MEANS
   → Found on Google Places ✓
   → Has accurate coordinates ✓
   → Has photos and reviews ✓
   → Matches your master list ✓
   → (Optional) Has Wikipedia article ✓

================================================================================
                         QUICK REFERENCE
================================================================================

What YOU provide in master_attractions_clean.py:
  - name (what to search for)
  - search_queries (alternative names)
  - category (your classification)
  - importance (your prioritization)
  - description (your write-up)
  - expected_rating (quality estimate)

What PIPELINE adds automatically:
  - latitude, longitude (Google Places)
  - image_urls (Google Places - 5 photos)
  - average_rating, total_reviews (Google Places)
  - opening_hours (Google Places)
  - address (Google Places)
  - website_url (Google Places)
  - historical_significance (Wikipedia)
  - tags (Wikipedia)
  - ticket_price_egyptian (calculated)
  - is_verified (TRUE if all pass)

How VERIFICATION works:
  1. You add to master list (Level 1: Human)
  2. Pipeline finds on Google Places (Level 2: Platform)
  3. Pipeline finds on Wikipedia (Level 3: Cultural)
  4. Data matches across sources (Level 4: Consistency)
  5. Inserts with is_verified=TRUE (Level 5: Database)
