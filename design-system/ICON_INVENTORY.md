# VOYO Icon Inventory

> Complete catalog of custom icons needed. Style: rounded line icons (Phosphor Icons base) + custom VOYO-specific icons.

---

## Icon Style Reference

**Base style:** Rounded line icons, 1.5px stroke, rounded caps
- **Reference library:** [Phosphor Icons](https://phosphoricons.com/) — use "regular" weight as starting point
- **Custom modifications:** Add VOYO-specific details to ~15 icons, the rest use Phosphor directly

**Sizes:**
| Usage | Size | Stroke | Canvas |
|-------|------|--------|--------|
| Inline | 16px | 1.5px | 20×20 |
| Standard | 24px | 1.5px | 28×28 |
| Feature | 32px | 2px | 36×36 |
| Hero | 48px | 2px | 56×56 |
